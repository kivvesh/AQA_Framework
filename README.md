# Фрейморк автотестов

## Запуск тестов

1. для тестирования ui - `pytest -m ui`
1. для тестирования api - `pytest -m api`


### Флаги для запуска
 * -m - маркеры для запуска тестов

## Структура проекта
  * core - модуль с функционалом работы тестов
    * dump_data - запись данных в файлы
    * image_processing - работа с изображениями
    * load_data - получение данных из файлов
    * logger - класс логгирования
    * request - класс для http-запросов
    * send_report - отправка информации по тестам во время их прохождения и отчет после них 
  * data - директория для выгрузки файлов во время прохождения тестов
  * logs - директория с файлами-логами
  * src - описана бизнес логика модулей
    * api - описанны api методы
    * pages - описаны ui-страницы и методы их взаимодействия
  * tests - тесты
  * configs - модуль с конфигурациями для тестового фреймворка
    * .env - общий конфигурационный файл
  * conftest - файл с фикстурами, хуками (динамика)
  * pytest.ini - файл для тестов со статикой, описаны маркера для запусков тесты
  * settings - настройки для работы всех модулей
